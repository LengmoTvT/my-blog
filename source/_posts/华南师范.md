## 华南师范

在华南学工公众号下的一站式预约网页里，注册账号的时候我们抓包后看到请求里包含[product]变量
```
data = {
    "mobile": "13333333333",
    "template": "regcode",
    "token": "send_token_8382cf1e2a8ea814fc9e44599f86ae94",
    "args[product]": "预约服务平台"
}
```
就此我们知道了他是一个短信内容的变量，但是她要用到图形验证码


![img_20260805031740.png](img_20260805031740.png)

但是纯数字干扰度小我们就要用的ddddorc，和获取图形验证码和send_token的接口如下


![img_20260805031905.png](img_20260805031905.png)

这边需要用<https://reservation.scnu.edu.cn/site/login/code?v=1785870432342>来获取图形验证码


![img_20260805032043.png](img_20260805032043.png)

后在第二个接口使用ddddorc进行识别输入
<https://reservation.scnu.edu.cn
/site/login/get-send-sms-token?security_code=czelu3>

```
{
"e": 0,
 "m": "操作成功",
 "d": { 
"token": "send_token_8382cf1e2a8ea814fc9e44599f86ae94",
 "expire_in": 600}
 }
```
最后填写到短信接口里的token参数里
```
data = {
    "mobile": "13333333333",
    "template": "regcode",
    "token": "send_token_8382cf1e2a8ea814fc9e44599f86ae94",
    "args[product]": "自定义内容"
}
```
